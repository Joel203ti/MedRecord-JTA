# Guion de presentación
1. Problema: revisión lenta de expedientes extensos.
2. Solución: extracción, resumen, dashboard y preguntas.
3. Demostración: subir PDF sintético, revisar métricas, preguntar y exportar informe.
4. IA responsable: sin diagnóstico, prescripción ni automatización de decisiones.
5. Tecnología: FastAPI, PyPDF, Responses API y GPT-4o en Microsoft Foundry.
6. Limitación: PDF debe contener texto seleccionable; OCR queda como mejora.
